Olympic Swimming

RDF Dataset and Ontology for Olympic Swimming Results

About the project

This project represents Olympic swimming competition data using RDF and Linked Data principles. It focuses on Japanese swimmers participating in the Tokyo 2020 Olympic Games.

The dataset describes athletes, swimming events, competitions and individual participation results.

Ontology

The project uses existing vocabularies such as FOAF and IPTC Sport Schema, together with custom classes and properties defined using RDF Schema.

Ontology namespace:
https://marcostardy.github.io/olympic-swimming/ontology/swimming#
